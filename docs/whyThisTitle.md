# 📄 [파이널 프로젝트 계획서] 멜키 (MelKie) - 순수 자바 코어 엔진 기반 페르소나 매칭 시뮬레이터

## 1. 기획 의도 및 주제 선정 배경

* **철학적 배경: 본연의 짝을 찾는 인류의 근원적 알고리즘**
세상에는 셀 수 없이 다양한 성향을 가진 사람들이 존재합니다. 인간은 일생을 거쳐 자신과 가장 완벽하게 맞물리는 '최적의 짝'을 찾아 결합하고, 생명을 잉태하여 세상을 유지시키고 발전시켜 나갑니다. 이것은 인류가 가진 가장 위대하고 본질적인 '자연의 매칭 알고리즘'입니다. 본 프로젝트는 이러한 인간의 숭고한 연결 과정을 컴퓨터 공학적 관점에서 디지털화하고 시뮬레이션하고자 하는 철학적 고찰에서 출발했습니다.
* **서비스 명칭의 의미: 멜키 (MelKie = Melt + Cookie)**
사람들은 누구나 사회라는 공간 속에서 처음에는 겉보기의 귀엽고 달콤한, 정형화된 **'쿠키(Cookie)'** 같은 페르소나를 띠고 살아갑니다. 하지만 진정한 최적의 짝을 만나 깊은 상호작용을 나누게 되면, 그 단단했던 겉모습은 무장 해제되고 서로를 향해 뜨겁게 **'녹아내리는(Melt)'** 본연의 자아를 드러냅니다. '멜키'는 바로 이 감정의 전이와 자아의 발견 과정을 완벽하게 추적하고 매칭해 주는 시스템입니다.
* **왜 이 주제인가? (기술적 타당성)**
복잡한 인간의 심리와 감정 전이 과정을 기성품 같은 외부 블랙박스 AI(LLM)에 의존하여 처리하는 것은 본질을 꿰뚫지 못하는 수박 겉핥기에 불과합니다. 따라서 입력된 텍스트를 형태소 레벨에서 직접 파싱하고, 감정의 변화를 객체지향적인 상태 패턴(State Pattern)으로 완벽하게 통제하며, 성향을 다차원 벡터로 추상화하여 수학적으로 매칭하는 '순수 코어 엔진'을 바닥부터 직접(From-scratch) 구현함으로써, 복잡한 인간관계의 역학을 CS 코어 지식으로 증명해내기 위해 본 주제를 선정했습니다.

## 2. MelKie 프로젝트의 핵심 경쟁력 (장점)

* **독보적인 기술적 근본력 (Zero-Dependency):** 텐서플로나 외부 API의 화려함에 기대지 않고, 오직 Java SE 표준 API만으로 텍스트 파싱 엔진, 상태 전이, 수학적 매칭 로직을 스스로 구축합니다. 단순 API 호출자가 아닌, 코어 원리를 통제하는 '하드코어한 개발 역량'을 증명합니다.
* **엄격한 객체지향 설계의 실증:** 인간의 감정이 '밀당 $\rightarrow$ 능글 $\rightarrow$ 치명'으로 넘어가는 과정을 다형성(Polymorphism)을 통해 코드 레벨에서 완벽히 제어하여, 논리적 흐름이 끊기거나 예기치 못한 답변(Hallucination)이 나오는 것을 원천 차단합니다.
* **사회적/심리적 가치 제공:** 유저들에게 텍스트 기반의 몰입형 롤플레잉을 제공함으로써, 평소 억눌려 있던 자신의 은밀한 성향(Melt)을 안전하게 표출하게 하고, 수학적 지표를 통해 자신과 100% 싱크로율을 자랑하는 이성의 페르소나를 진단받는 재미와 통찰을 동시에 제공합니다.

## 3. 개발 목표 및 시스템 기능

* **제로 의존성(Zero-Dependency):** 외부 라이브러리 없이 순수 자바만으로 완벽히 구동.

* **실시간 텐션 스코어링:** 정규표현식(Regex)과 Stream API를 통해 입력된 대사 문자열을 고속 분석하여 텐션 점수(Melt Rate)를 측정.
* **동적 감정 전이 시스템:** 텐션 점수 변화에 따라 페르소나의 상태가 밀당(Chilly) 단계에서 능글(Flirty), 치명(Steamy) 상태로 완전히 독립되게 전이됨.

## 6. UML 및 흐름 설계 명세

* **클래스 다이어그램 (상태 패턴):** 감정 상태를 통제하는 `MeltingState` 인터페이스를 선언하고, 이를 `ChillyState`, `FlirtyState`, `SteamyState` 클래스가 구현.
* **클래스 다이어그램 (컨텍스트 및 엔진):** 세션을 통제하는 `MeltingContext`, 정규식 가중치를 계산하는 `TextAnalysisEngine`, 수학적 분석을 수행하는 `MatchEngine`으로 구성.
* **시퀀스 다이어그램:** 유저 입력 $\rightarrow$ `TextAnalysisEngine` 점수 산출 $\rightarrow$ `MeltingContext` 업데이트 $\rightarrow$ `MeltingState` 상태 전이 평가 $\rightarrow$ 다형성에 의한 응답 반환.

## 7. 시스템 구조 및 프로그램 설계 (Architecture & Design)

### 7-1. NLP-Free 1:1 대화 알고리즘 (Rule-Based Chat Engine)

LLM 의존 없이 자연스러운 1:1 대화를 구현하기 위해 **[입력 $\rightarrow$ 키워드 매칭 $\rightarrow$ 점수 연산 $\rightarrow$ 조립형 응답]** 파이프라인을 구축합니다. 단순한 if-else 하드코딩이 아닌, 탐색 시간 복잡도를 $O(1)$로 최적화한 고성능 텍스트 분석 엔진입니다.

1. **Rule-Based Lexicon Engine (어휘 사전):** 자바 `HashMap`과 정규표현식(`Pattern`, `Matcher`)을 이용해 핵심 감성 키워드 사전을 메모리에 구축합니다. 정규식을 통해 수백 가지의 한국어 어미 변형을 단 50개의 코어 패턴으로 압축하여 필터링합니다.
* *가점 키워드(+):* "예쁘|귀여|만질|좋아|너|오늘" (적극성 증가)
* *감점 키워드(-):* "싫|아니|별로|왜|그냥" (순종성 증가)


2. **Score-Driven State Transition (상태 전이):** 추출된 키워드를 바탕으로 텐션 점수(Melt Rate)를 산출합니다. 점수가 임계점(30, 70)을 돌파할 때마다 다형성을 활용하여 `State` 객체를 실시간으로 갈아끼웁니다 (`Chilly` $\rightarrow$ `Flirty` $\rightarrow$ `Steamy`).
3. **Dynamic Response Assembly (동적 텍스트 조립):** 고정된 대사의 단조로움을 극복하기 위해, 텐션 증감폭에 따라 상황에 맞는 행동 접두사(예: *살짝 귓속말로*, *팔짱을 끼며*)를 대사 앞에 동적으로 결합(String Concatenation)하여 실제 AI와 대화하는 듯한 문맥을 완성합니다.

### 7-2. 수학적 매칭 모델 (Cosine Similarity)

3턴의 대화 종료 후, 누적된 3차원 유저 배열 `[주도성, 순종성, 적극성]`을 바탕으로 최적의 짝을 판별합니다.

$$\text{Similarity} = \frac{\sum_{i=1}^{n} (A_i \times B_i)}{\sqrt{\sum_{i=1}^{n} A_i^2} \times \sqrt{\sum_{i=1}^{n} B_i^2}}$$

위 코사인 유사도 공식을 `MatchEngine` 내부에서 순수 자바 반복문과 `Math.pow`, `Math.sqrt` 만으로 치환 구현하여, 무거운 머신러닝 연산 없이 100% 싱크로율의 짝을 수학적으로 도출합니다.
